# System Map

## Desktop stack
- WM: Hyprland
- Panel: Waybar
- Launcher: Rofi (drun)
- Terminal: Kitty
- Browser: Brave

## Replacements for DMS

- Clipboard → cliphist
- Notifications → dunst

- HJKL = navigation
